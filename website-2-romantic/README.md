# Website 2: Cute & Romantic Wedding Invitation

This is a **completely standalone, self-contained website** for the Cute & Romantic digital wedding invitation of **Kouslya & Mohan**.

Guests viewing this website see **only** this romantic invitation. There are no links or access to any other versions.

## Features
- **Welcome Experience:** Friendly waving greeting from the couple with floating hearts and sparkle particles (`assets/animations/romantic-wave.svg`).
- **Aesthetic:** Soft Blush Pink, Peach, and Rose-Gold palette with curved modern elements.
- **Audience:** Friends, colleagues, cousins, and youth.
- **Photographs:** Features original portraits of Bride Kouslya and Groom Mohan with tap-for-sparkle interactive hearts.
- **RSVP:** Direct **RSVP on WhatsApp** button prefilled with greeting message.
- **Navigation:** Direct **Get Directions** in Google Maps + **Copy Address**.
- **Calendar & Countdown:** Live countdown to the wedding + Add to Google Calendar & Apple/iCal.

## Deployment to GitHub Pages
To publish this website independently:
1. Create a new GitHub repository (e.g. `kouslya-mohan-romantic`).
2. Upload or push all files inside this folder (`website-2-romantic/`) to that repository.
3. Enable GitHub Pages in repository **Settings** &rarr; **Pages** &rarr; Branch: `main` / Folder: `/ (root)`.
4. Your live invitation URL will be:  
   `https://YOUR_USERNAME.github.io/kouslya-mohan-romantic/`
